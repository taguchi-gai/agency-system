■ 2. 追加した機能

【A】お支払い方法を選べるようにしました

　お申し込み時に、まず「個人」か「法人」かを選んでいただきます。

　・個人のお客さま　… カード ／ PayPay ／ 現金
　・法人のお客さま　… 上記に加えて「請求書払い（月末締め・銀行振込）」

　現金と請求書払いを選んだ場合は決済画面に進まず、そのままお申し込みが完了します。
　請求書払いを選ぶと、請求先（法人名・部署・ご担当者名・請求先住所）の入力欄が表示されます。

【B】現金の場合のお金の流れ

　施工代理店が施工当日にお客さまから現金を受け取る前提で作りました。

　　１．施工代理店がその場で現金を回収（回収したことを画面に記録します）
　　２．施工代理店は自社の取り分80%を手元に残し、残り20%を本部へお振り込み
　　３．本部から施工代理店へ、その20%分の請求書を発行（支払管理画面のボタンで作成）
　　４．本部から取次店へ10%をお振り込み

　現金は決済代行会社を通さないため、手数料はかかりません。
　また、回収の記録をしないと施工完了の報告ができないようにしてあります
　（未回収のまま案件が完了し、本部が入金を追えなくなることを防ぐためです）。

　※ 振込手数料は施工代理店のご負担という前提で作っています。相違があればお知らせください。

【C】法人のお客さま向けの請求書（新しい「顧客請求」画面）

　月末締めで、法人ごとに1枚の請求書にまとめます。
　同じ法人から月内に複数のお申し込みがあっても、請求書は1枚にまとまります。

　・締めは「施工が完了した月」です（施工前のお客さまには請求しません）
　・お支払期限の初期値は「翌月末」、振込手数料はお客さまご負担の表記にしています
　・宛先はお客さまが申込時に入力された請求先をそのまま使います

【D】請求書が4種類になりました

　　消耗品　　… 消耗品受発注画面の各注文から作成
　　加盟金　　… 契約書管理画面の各契約から作成
　　現金回収　… 支払管理画面の「現金案件の精算」から作成（施工代理店宛て）
　　顧客請求　… 顧客請求画面から作成（法人のお客さま宛て）

　いずれも「作成済み → 送付済み → 入金済」で管理し、送付後は内容を変更できません。

【E】施工代理店に「取次機能」を付与できるようにしました

　本部の施工代理店管理画面にボタンを追加しました。押すだけで、
　その施工代理店に自社用の注文フォームと専用QRコードが作られます。

　ハウスクリーニングやエアコン清掃の業者様が、訪問先で
　「車の除菌消臭もいかがですか」とその場でご案内するような場面を想定しています。

　・自社で受けて自社で施工した案件は、取次手数料も自社の取り分となり合計90%です
　　（本部10%。ご回答いただいた考え方のとおりです）
　・自社の案件は本部が施工店を探す必要がないため、施工日を「当日」から選べます
　・受付と同時に自動で自社の案件になるため、本部の割り当て作業は不要です
　・自社で受けた案件を他社の施工代理店が施工する場合は、取次分の10%のみとなります

　デモでは「東海カークリーン」に取次機能を付与した状態にしてあります。
　施工代理店としてログインすると、メニューに注文フォームが増えているのが確認できます。

■ 4. ご確認・ご判断をお願いしたい点

　①【法人の請求書払い】
　　取次店が「法人・請求書払い」を選べばそのまま成立でよろしいでしょうか。
　　それとも本部の事前承認を挟みますか。（掛け払いのため未回収のリスクがあります）

　②【振込手数料の負担】
　　法人のお客さまへの請求書は「振込手数料はお客さまご負担」の表記にしています。
　　現金分を施工代理店から回収する際も、施工代理店のご負担という前提です。
　　いずれも相違がないかご確認ください。

　③【現金分の回収と、カード分のお支払いの相殺】
　　同じ施工代理店に対して、同じ月に
　　「本部 → 施工代理店（カード分の80%）」と「施工代理店 → 本部（現金分の20%）」が
　　両方発生します。それぞれ別々に処理しますか、差し引いて1本にまとめますか。

　④【領収書】
　　現金をお受け取りの際にお客さまへお渡しする領収書は、
　　本部（株式会社ワイズ）名義でシステムから発行する想定でよろしいでしょうか。

　⑤【取次店ご自身が施工を申し込まれる場合】
　　中古車販売店様が在庫車を施工されるケースです。この場合、
　　その取次店に取次手数料10%は付きますか。また法人の請求書払いの対象になりますか。

　⑥【複数台のまとめ申し込み】
　　現在は1回のお申し込みにつき1台です。中古車販売店様が在庫車を何台かまとめて
　　依頼されるケースを想定し、1回の申し込みで複数台（車種ごとに台数を指定）を
　　受け付けられるようにする予定です。
　　この想定で問題ないか、また実際にそうした依頼が発生しそうかをお聞かせください。

　⑦【自社取次の案件について】
　　【E】のとおり、取次機能を付与した施工代理店の案件は本部の割り当てを経由しません。
　　施工前確認の署名と完了報告は必ず記録に残りますが、本部の画面での見え方について
　　ご希望があればお知らせください（件数だけ表示する、一覧で確認できるようにする等）。
