# 代理店管理システム 機能要件書

## 1. 地理的マッチング機能（半径検索）

### 概要
お客さまの施工現場住所から指定した半径（5km、10km等）以内に位置する施工代理店を自動抽出し、割り当て・通知する機能。

### 詳細要件

#### 1.1 お客さまの施工現場住所の入力
- **入力方法**：取次注文フォームで住所を入力（現在は「希望日」までだが、住所を追加）
- **入力項目**：
  - 都道府県
  - 市区町村
  - 番地・建物名
  - またはフリーテキスト入力

#### 1.2 住所から座標への変換（ジオコーディング）
- **API選定**：
  - 選択肢1：Google Maps Geocoding API（精度高、有料）
  - 選択肢2：国土地理院 API（無料、日本国内専用）
  - 選択肢3：OpenStreetMap Nominatim（無料、精度は中程度）
- **動作**：お客さまが住所を入力 → API呼び出し → 緯度・経度を取得
- **キャッシング**：同じ住所へのAPI重複呼び出しを回避

#### 1.3 施工代理店の座標登録
- **入力者**：本部（施工代理店マスタ登録時）
- **入力内容**：
  - 施工代理店の本社住所（必須）
  - 緯度・経度（自動取得または手入力で確認）
  - 対応エリア（複数店舗がある場合は対応可能な地域一覧）
- **更新**：住所変更時は座標も再取得

#### 1.4 距離計算ロジック
- **計算方式**：ハバーサイン公式
  - 地球を球体と仮定し、2点間の大円距離を計算
  - 精度：±0.5% 程度（実用上は十分）
- **計算式実装**：
  ```
  d = 2 * R * arcsin(sqrt(sin²((lat2-lat1)/2) + cos(lat1)*cos(lat2)*sin²((lon2-lon1)/2)))
  R = 6371 (地球の平均半径：km)
  ```

#### 1.5 マッチング結果の抽出
- **ロジック**：
  1. お客さまの住所座標を取得
  2. 全施工代理店の座標との距離を計算
  3. 指定半径以内の施工代理店をフィルタ
  4. 稼働状態で並び替え（稼働中 > 準備中）
- **結果表示**：本部画面に「マッチした施工代理店一覧」を表示
  - 施工代理店名
  - 距離（○○km）
  - 現在のステータス
  - 最近の施工実績件数

#### 1.6 半径設定の柔軟性
- **ユーザー指定**：本部が「5km」「10km」「15km」など選択可能
- **デフォルト**：15km（設定で変更可能）
- **複数条件指定**：距離が近い順に表示し、本部が選択

### 非機能要件
- **レスポンス**：住所入力から結果表示まで 2秒以内
- **精度**：都市部で ±100m、地方で ±500m 程度
- **スケーラビリティ**：施工代理店が 1,000 社程度まで対応

## 2. 通知機能

### 概要
施工代理店に対して、マッチした注文情報を自動通知する。

### 通知方式（複数選択可）

#### 2.1 メール通知
- **タイミング**：本部が施工代理店を割り当てた時点
- **内容**：
  - 注文番号
  - お客さまの情報（住所・車種・希望日）
  - 割り当て理由（「〇〇様の現場から△km圏内のため」）
  - 対応可否の回答期限（24時間以内 等）
- **宛先**：施工代理店の登録メールアドレス

#### 2.2 アプリ内通知
- **タイミング**：施工代理店がシステムにログインしたときに表示
- **内容**：メール同様
- **既読管理**：施工代理店が確認したかどうかを追跡

#### 2.3 SMS 通知（オプション）
- **コスト**：1通あたり数円（月間数千通程度）
- **用途**：重要な案件のみ、または対応急ぎの場合

### 通知履歴管理
- **記録内容**：
  - 送信日時
  - 送信先（施工代理店）
  - 対応可否の回答日時
  - 最終ステータス（完了 / 不可）
- **監視**：本部が「回答待ち」の案件を一覧表示

## 3. 本部UI の追加・変更

### 施工注文受付画面の変更
- **現在**：「施工店を割り当て」ボタン → 手動選択
- **変更後**：
  1. お客さま住所を自動入力（取次フォームから）
  2. 「半径〇km以内の施工代理店を検索」ボタン
  3. マッチ結果をリスト表示
  4. リストから選択 → 通知送信

### 施工代理店マスタ管理画面の追加
- **入力項目の追加**：
  - 緯度・経度（自動取得 or 地図クリック入力）
  - 対応可能エリア（複数選択）
  - 通知メールアドレス
- **地図表示**：登録されている全施工代理店の位置を地図上に可視化

## 4. 施工代理店側の変更

### 案件詳細画面
- **追加情報**：「あなたの店から △km」と距離を表示
- **位置情報**（マップ）：お客さまの施工現場の住所を地図上に表示

## 5. データベース スキーマ追加

### contractors テーブルへの追加カラム
```sql
ALTER TABLE contractors ADD (
  latitude DECIMAL(9, 6),           -- 緯度
  longitude DECIMAL(9, 6),          -- 経度
  service_areas VARCHAR(500),       -- 対応エリア（JSON配列等）
  notification_email VARCHAR(255),  -- 通知用メールアドレス
  notification_sms VARCHAR(20),     -- 通知用 SMS（オプション）
  last_geocoded_at TIMESTAMP        -- 最後にジオコーディングした時刻
);

CREATE INDEX idx_contractors_location ON contractors(latitude, longitude);
```

### service_orders テーブルへの追加カラム
```sql
ALTER TABLE service_orders ADD (
  customer_address VARCHAR(500),    -- お客さま施工現場の住所
  customer_latitude DECIMAL(9, 6),  -- お客さま施工現場の緯度
  customer_longitude DECIMAL(9, 6), -- お客さま施工現場の経度
  assigned_distance_km DECIMAL(5, 2), -- 割り当てた施工代理店との距離
  assignment_reason VARCHAR(255),   -- 割り当て理由
  notification_sent_at TIMESTAMP,   -- 通知送信時刻
  notification_response_at TIMESTAMP -- 施工代理店の回答時刻
);
```

## 7. 今後の拡張案

- **機械学習による最適マッチング**：距離だけでなく、過去の施工実績、応答率、時間帯等から「最適な施工代理店」を推定
- **リアルタイム交通時間考慮**：距離ではなく、運転時間ベースのマッチング
- **複数施工代理店への同時提案**：1件の案件を複数店に投げて、早く応答した店に割り当て
