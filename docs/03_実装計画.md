# 代理店管理システム 本番開発 実装計画

## 1. プロジェクト概要

### ゴール
「代理店管理システム」のモック HTML から本番システムへの移行。
特に地理的マッチング機能（お客さまの施工現場から半径 5〜10km 以内の施工代理店の自動抽出・通知）の実装。

### 現状
- ✅ モック v2 が GitHub Pages で公開中
- ✅ 4 層構造（本部・加盟店・取次店・施工代理店）の画面設計は完了
- ❌ データベース・バックエンド未実装
- ❌ ジオコーディング・距離計算機能未実装
- ❌ リアルタイム通知機能未実装

## 5. リスク管理

| リスク | 影響度 | 対策 |
|---|---|---|
| ジオコーディング API の精度が期待値以下 | 高 | Phase 1 で複数 API を比較テスト。Google Maps API への切り替え選択肢を用意 |
| ジオコーディング API のレスポンス遅延 | 中 | キャッシング・事前計算・非同期処理で対応 |
| 本部・施工代理店からのテスト依頼が多い | 中 | 事前に UI プロトタイプを FigJam で共有し、要望を早期に吸い上げ |
| 本番環境でのトラブル | 高 | Phase 5 の負荷テスト・UAT を十分に確保。本番デプロイ前に Staging 環境での 1 週間動作確認 |
| 通知が施工代理店に届かない（メール配信失敗） | 中 | 通知失敗時のリトライロジック。管理画面で送信失敗を可視化し、本部が手動再送可能に |
